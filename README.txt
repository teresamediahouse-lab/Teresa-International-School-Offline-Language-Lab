TERESA INTERNATIONAL SCHOOL — OFFLINE LANGUAGE LAB

OPENING THE APP
1. Extract the ZIP into a permanent folder.
2. Open index.html in Chrome or Edge.
3. Keep using the same browser profile and same extracted folder so local data stays available.

LEARNING STUDIOS VS ASSIGNMENTS
Learning studios are independent practice activities for students. They use the lesson and word bank created for that student's exact class and subject. They do not load the content of a teacher assignment.

Teacher assignments appear under My assignments. Opening an assignment launches a separate assignment activity, with the assignment's own title, passage/instructions, or target speaking words. Speaking assignments let the student move through the teacher's target words and use the microphone speaking check.

EDITING CONTENT
Teachers can use Lesson editor to create or replace the lesson passage for a specific subject and class, and add vocabulary/speaking words one per line. Word format: word | meaning | example sentence | pronunciation hint. Save the lesson to update that class's studio content. Use Assignments to set separate classwork with its own passage and/or speaking words. Word manager can also add individual words.

IMPORTANT CONTENT NOTE
The starter passages are examples for Class 6 only. For other classes, create a lesson for each class and subject. The app no longer silently reuses a Class 6 passage for other classes.

SPEAKING RECOGNITION
Microphone recognition depends on browser support and permissions. Chrome speech recognition may use an online service; fully offline recognition is not guaranteed. Hindi recognition is used as an approximation for Sanskrit because browser support for Sanskrit recognition is generally unavailable.

SAVING DATA
Accounts, lessons, words, assignments and results are saved in local browser storage on this computer. Use the same browser profile and folder, do not clear browser data, and download a backup from Progress reports regularly. This single-file offline app does not sync between computers.

SECURITY
This is a local prototype, not a production student information system. Passwords are stored locally and are not securely hashed. Do not use sensitive information.
